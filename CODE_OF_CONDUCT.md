# Code of Conduct

## Our Pledge
We pledge to make participation in our project a harassment-free experience for everyone.

## Our Standards
Examples of behavior that contributes to a positive environment include:
- Using welcoming and inclusive language
- Being respectful of differing viewpoints

## Enforcement Responsibilities
Project maintainers are responsible for clarifying standards.

## Scope
This Code of Conduct applies within all project spaces.

## Enforcement
Instances of abusive behavior may be reported to the maintainers.

## Enforcement Guidelines
Maintainers will follow fair and consistent enforcement guidelines.

## Attribution
This Code of Conduct is adapted from common open-source community standards.
